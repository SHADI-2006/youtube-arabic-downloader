How the Arabic subtitle is chosen

  1. Human-made Arabic subtitleIf the uploader published one, it's used as-is — nothing beats it.
  2. Gemini translationReads the whole English subtitle file at once, so sentences stay connected instead of being translated cue-by-cue.
  3. YouTube's auto-translationUsed if Gemini is unavailable or its free limit is reached.
  4. Google TranslateAlways-free final fallback, so a translation always lands.
